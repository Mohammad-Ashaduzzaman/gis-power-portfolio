# Portfolio design system — V6

## Core tokens

| Role | Value |
|---|---|
| Paper | `#f8f9f5` |
| Surface | `#fffefa` |
| Text | `#182321` |
| Forest | `#304a32` |
| Dark forest | `#1e3526` |
| Sage | `#e5ece2` |
| Muted text | `#66736d` |
| Border | `#dde4da` |

Typography uses an installed Inter font where available, followed by system sans-serif fonts. No remote font request is required. The small portrait quote uses Georgia italic. Analytical map colors preserve semantic categories such as water, risk, condition, and land cover.

## Homepage

Large left-aligned positioning statement; blended portrait on the right; two clear calls to action; four sage-icon capability cards; editorial content sections; a searchable three-column project gallery; warm, responsive quick-preview overlays.

## Project pages

Fixed forest navigation rail; independently scrolling context panel; map-first workspace; closed detail drawer at entry; collapsible bottom data drawer; persistent Project Details control. Header search and map selectors remain available at small sizes. On mobile, the context panel opens over the map and has a dedicated close control.

## Interaction principles

A click selects and opens details. Hover provides a lightweight preview. Checkboxes support comparison. Table rows link to their corresponding assets where a relevant entity is available. Tables support column sorting and current-tab CSV export. Keyboard focus is visible. The homepage modal traps focus and restores it on close. Reduced-motion preferences are respected.
